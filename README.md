#  Retail Sales Excel Dashboard

##  Project Overview

This project is an interactive retail sales dashboard built in Microsoft Excel to analyze sales performance, customer demographics, and order trends.

##  Features

- Sales analysis by State
- Sales distribution by Gender
- Orders by Sales Channel
- Age Group vs Gender Analysis
- Interactive Dashboard using Slicers
- Dynamic Pivot Tables and Pivot Charts

##  Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning
